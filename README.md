- **Build Automation**: Every module includes a robust `Makefile` for easy compilation, cleaning, and testing.
- **Algorithm Analysis**: Code is optimized for time and space complexity, adhering to course requirements.
- **Reference Included**: Contains both personal solutions and TA-provided reference answers for comparative learning.
